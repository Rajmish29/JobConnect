
# JobConnect

A full-stack job portal built with React, Node.js, Express and MongoDB.

## Features

- User Signup and Login
- JWT Authentication
- Job Listing and Search
- Job Details and Application
- Apply for Jobs
- Save Jobs
- User Profile Management
- Admin Dashboard
- Admin Job Management
- Application Status Management
- Remote Jobs Integration using Remotive API

## Tech Stack

- React
- JavaScript
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- CSS

## Installation

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
node server.js
```

## Environment Variables

Create a `.env` file inside the `server` folder.

Add your MongoDB URI, JWT secret and admin credentials.

**Note:** Never upload your actual `.env` file to GitHub.
